# 4D Results App

A simple Flask web application to display 4D lottery results.

## Setup

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Run the application:
```bash
python app.py
```

3. Open http://localhost:5000 in your browser

## Features

- Display 4D lottery results from CSV data
- REST API endpoint at `/api/results`
- Simple web interface
